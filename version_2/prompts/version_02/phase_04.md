# Phase 04: 지능형 인사이트 및 외부 알림 서비스 🔔

## 🎯 목표
단순한 데이터 수집을 넘어, 여러 소스의 데이터를 결합하여 트렌드의 신뢰도를 평가하고 실시간으로 인사이트를 전달하는 지능형 시스템을 완성합니다.

## 🛠️ 주요 개발 작업

### 1. 다중 소스 교차 검증 및 신뢰도 점수 (Reliability Score)
- **파일 위치**: `services/reliability_service.py` (신규)
- **주요 기능**:
  - **Cross-Verification**: Google Trends 외에 네이버, 언론사 RSS, 커뮤니티 화제성 등을 종합.
  - **신뢰도 점수 산출**: 여러 소스에서 공통적으로 언급되는 정도에 따라 '트렌드 신뢰도 점수' 부여.
  - **급상승 감지(Anomaly Detection)**: 단시간 내에 신뢰도 점수가 급등하는 키워드를 별도 분류.

### 2. 지능형 일간 리포트 생성 (`Trend Report`)
- **파일 위치**: `services/report_service.py` (신규)
- **주요 기능**:
  - **Daily Summary**: 지난 24시간 동안의 핵심 트렌드를 AI가 종합하여 한 페이지 분량의 리포트 생성.
  - **Insight Extraction**: 단순 정보 나열이 아닌, 해당 트렌드가 시장이나 사회에 미칠 영향 분석 포함.

### 3. 외부 채널 실시간 알림 연동
- **파일 위치**: `services/notification_service.py`
- **주요 기능**:
  - **Channel Connectors**: Telegram Bot, Slack Webhook, Email API 연동.
  - **조건부 알림**: 신뢰도 점수가 특정 기준(예: 80점 이상)을 넘을 때만 모바일 푸시 알림 발송.
  - **인터랙티브 메시지**: 알림 메시지 내에 요약 내용과 대시보드 바로가기 버튼 포함.

### 4. DB 성능 최적화 및 최종 폴리싱
- **파일 위치**: `database/optimization.py`
- **주요 기능**:
  - **Indexing**: 대규모 데이터 조회 성능 향상을 위한 DB 인덱싱 최적화.
  - **Auto-Archiving**: 오래된 데이터(예: 30일 경과)를 별도 백업 DB로 이동시켜 메인 DB 경량화 유지.
  - **Final UI/UX**: 전체적인 디자인 테마(다크/라이트) 및 모바일 최적화 레이아웃 완성.

## ✅ 완료 기준
- 신뢰도가 검증된 양질의 트렌드 정보만 선별하여 알림이 오는가?
- AI가 생성한 일간 리포트가 단순 뉴스 요약보다 깊이 있는 인사이트를 담고 있는가?
- 수만 건의 데이터가 DB에 쌓여도 대시보드 로딩 속도가 3초 이내로 유지되는가?
