# Phase 03: 하이브리드 UX 및 시각화 고도화 🎨

## 🎯 목표
수집된 데이터를 기반으로 사용자에게 시각적 인사이트를 제공하고, 자동/수동 데이터가 혼합된 환경에서도 최적의 검색 경험을 제공합니다.

## 🛠️ 주요 개발 작업

### 1. 트렌드 타임라인 시각화
- **파일 위치**: `components/trend_chart.py` (신규)
- **주요 기능**:
  - **관심도 추이**: 키워드별 Google Trends 지수 변화를 선 그래프(`Plotly`)로 시각화.
  - **순위 변화**: 시간대별 TOP 10 키워드의 순위 변동 추적 차트.
  - **워드클라우드**: 실시간 화제성이 높은 키워드를 시각적으로 표현.

### 2. 하이브리드 키워드 및 구독 관리
- **파일 위치**: `components/sidebar.py`, `services/subscription_service.py` (신규)
- **주요 기능**:
  - **관심 키워드 구독**: 사용자가 특정 키워드를 '고정(Pin)'하면 해당 키워드는 분석 주기마다 우선적으로 업데이트.
  - **통합 검색 큐**: 자동 수집된 트렌드와 사용자가 직접 입력한 키워드를 하나의 대시보드에서 통합 관리.

### 3. 통합 검색 필터 및 히스토리 UI
- **파일 위치**: `components/search_history.py`
- **주요 기능**:
  - **멀티 필터링**: 소스(`auto`/`manual`), 카테고리, 날짜 범위를 기준으로 결과 필터링.
  - **상세 결과 카드**: AI 요약 내용과 원본 뉴스 링크를 고급스러운 카드 레이아웃으로 배치.
  - **데이터 내보내기**: 필터링된 검색 결과를 CSV 또는 Excel로 출력하는 기능 (엑셀 한글 깨짐 방지를 위해 `utf-8-sig` 인코딩 적용).

## ✅ 완료 기준

- 수천 건의 DB 데이터 사이에서 특정 카테고리의 트렌드를 1초 내로 필터링해 보여주는가?
